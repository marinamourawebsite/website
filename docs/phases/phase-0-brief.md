# Phase 0 Brief — Scaffold

## Objective

Bootable Astro + Tailwind skeleton: theme tokens, self-hosted fonts, Base layout, empty index page. Dev server renders the empty layout with the correct background and fonts; `npm run build` is green.

## Decisions already made (do not re-decide)

1. **Git**: this directory is NOT a git repository yet. Your first step is `git init` on branch `main`, add a `.gitignore` (`node_modules/`, `dist/`, `.astro/`, `.DS_Store`), then commit the pre-existing project files (`CLAUDE.md`, `SPEC.md`, `PLAN.md`, `GUIA.md`, `design/`, `docs/`, `public/admin/config.yml`, `.claude/`) as `chore: add project docs, agents and CMS config`. All scaffold work goes in subsequent conventional commits. The reviewer depends on git history existing.
2. **Commit style**: conventional commits, one logical change per commit, **no co-author trailers and no "Generated with Claude Code" footers** — end each message at the last content line. This is a repo-owner requirement and overrides any default workflow.
3. **Node**: global Node is v20.0.0, below Astro 5's engine floor (^20.3.0). asdf has 22.22.2 installed. Create `.tool-versions` in the repo root with `nodejs 22.22.2` and use that version for all commands (`asdf` picks it up automatically from the file). If install/build still fails on engines, report `blocked` — do not downgrade Astro to work around it.
4. **Fonts** (SPEC §2), self-hosted via Fontsource packages only:
   - `@fontsource/cormorant-garamond` — weights 500, 600 (display serif)
   - `@fontsource/allura` — weight 400 (script accent)
   - `@fontsource/poppins` — weights 400, 500, 600 (sans body; chosen over Inter to match the rounded geometric feel of the reference)
   Import only these weights (per-weight imports, not the full family).
5. **Tailwind**: current official Astro + Tailwind setup (Tailwind v4 via `@tailwindcss/vite`). All tokens declared with `@theme` in `src/styles/global.css`:
   - Colors, exactly as SPEC §2: `bg` #F5F2ED, `surface` #FCFBF8, `sage` #8FA081, `sage-dark` #76866A, `ink` #2E2E2C, `muted` #6E6E6A, `line` #E4E0D7. These hex values live in `global.css` ONLY — nowhere else, ever.
   - Font families: `--font-serif` → "Cormorant Garamond", `--font-script` → "Allura", `--font-sans` → "Poppins" (each with sensible fallback stacks).
6. **Astro**: static output (default). No adapters, no integrations beyond Tailwind. TypeScript config as generated by the Astro scaffold is fine.

## Scope

**In:**
- `package.json`, lockfile, `astro.config.mjs`, `tsconfig.json` (as generated), `.gitignore`, `.tool-versions`
- `src/styles/global.css` — Tailwind import + `@theme` tokens
- `src/layouts/Base.astro` — `<html lang="pt-BR">`, charset/viewport meta, `title` + `description` props wired to `<title>`/meta description, font imports, global.css import, `<slot />`, body styled with `bg-bg text-ink font-sans`
- `src/pages/index.astro` — renders `Base` with an empty `<main>` and a placeholder title/description passed as props (e.g. "Marina Moura"). **No other visible copy** — all real copy arrives via content JSON in Phase 1 (CLAUDE.md rule 2).

**Out (do not touch):**
- Components, `src/content/`, zod schemas, `Icon.astro` (Phase 1)
- `public/admin/` — config.yml already exists; leave it exactly as is (Phase 3)
- SEO/OG tags beyond basic title/description, favicon, analytics slot (Phase 4)

## Files expected to change

New: `.gitignore`, `.tool-versions`, `package.json`, `package-lock.json`, `astro.config.mjs`, `tsconfig.json`, `src/styles/global.css`, `src/layouts/Base.astro`, `src/pages/index.astro`. Nothing else.

## Acceptance criteria

1. `npm run build` exits 0 with zero errors.
2. `dist/index.html` contains `lang="pt-BR"` and the page background resolves to `#F5F2ED` via the `bg` token.
3. All three font families are bundled locally (woff2 files in `dist/`), only the specified weights; no requests to Google Fonts CDN anywhere.
4. No raw hex colors in any file except the `@theme` block in `global.css`.
5. No hardcoded user-visible copy beyond the `<title>` placeholder.
6. Git log shows conventional commits with no attribution trailers/footers.
7. `docs/phases/phase-0-report.md` written per the executor output contract.
